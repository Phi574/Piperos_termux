# Contributing

Contributions are accepted under GPL-3.0-only unless a file explicitly
declares another compatible license inherited from upstream.

Before submitting a change:

1. Keep upstream copyright and SPDX notices.
2. Do not add prebuilt binaries to Git history.
3. Run `./scripts/validate-config.sh`.
4. Run `python3 -m unittest discover -s tests -v`.
5. Document changes that affect the runtime contract or package ABI.

By contributing, you certify that you have the right to submit the work
under its stated license.
